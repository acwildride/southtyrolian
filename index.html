About this site

Two full nodes – Nodus Tyrolensis Stettiner and Fanes – run at home in South Tyrol, over Tor, with a full transaction index. A small server decodes every block into own databases: blocks, transactions, inputs, outputs and the complete UTXO set with the price at which each coin was created.

Everything on this page is computed from that data – no third-party on-chain API. The macro and weather pages use public sources, named on each page.

Nothing here is financial advice.
